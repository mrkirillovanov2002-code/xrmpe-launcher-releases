# ZoneLink 0.6.1.3 относительно 0.6.1.2

- Исправлено восстановление устаревшей или повреждённой копии `armbands.db` в изолированном каталоге `.zl-bands`; исходные игровые архивы не меняются.
- Для локально собранного косметического пакета с отличающимся эталонным SHA-256 добавлено предупреждение с выбором: продолжить без повязок, включить на свой риск или отменить. Принудительное включение ограничено проверенным содержимым штатного сборщика и запоминается только для точного хеша пакета и версии сборщика.
- Журнал сообщает этап, ожидаемый и фактический SHA-256, размер и источник пакета. Подписи обновлений, проверка игрового аддона и защита от небезопасного DB не ослаблены.
- Изменения других функций ZoneLink не предусмотрены; игровые проверки этой версии требуют отдельной приёмки.

# Кандидат ZoneLink 0.6.1.2 относительно 0.6.1.1

- Локальный сборщик повязок сообщает точный относительный файл, ожидаемый и обнаруженный SHA-256 и доступную версию PvP-аддона вместо Python traceback. Проверка совместимости остаётся обязательной.
- Поддержана проверенная редакция PvP 1.4.7 от 25 октября 2026: косметические ресурсы совпадают, локальная сборка дала исходный SHA-256 DB и 120 предпросмотров. Другие неизвестные хеши по-прежнему отклоняются.
- Проверка обновлений различает сетевую ошибку, тайм-аут и ошибку проверки; краткий отчёт без личных путей сохраняется локально. При сетевом сбое вскоре после запуска делается одна отложенная повторная попытка для подключения через VPN.
- Совместимость и обновление на другом ПК требуют подтверждения по диагностике. Этот кандидат не опубликован.

# Изменения ZoneLink 0.6.1 относительно 0.6.0

- «Мастерская»: один переключатель 3D-светящихся повязок. Старый выбор тканевых DDS и кнопка ручной установки убраны из интерфейса.
- Включение автоматически создаёт локальный косметический DB для 30 PvP-костюмов и трёх стартовых форм из проверенной установленной игры. Готовые OGF/DDS/DB не входят в публичный пакет.
- Выключение возвращает штатный вид при следующем запуске без замены игровых архивов. Прежняя сохранённая настройка DDS не включает 3D-пакет автоматически.
- Галерея 30 костюмов сохранена; добавлено автоматическое создание текстурированных изображений четырёх ракурсов из установленной игры; изображения не входят в публичный пакет.
- Клиентский профиль `-fsltx` действует только с `xrmpe_pvp.addon`; dedicated и другие аддоны остаются без косметики.
- Штатные карты, экономика PvP, параметры аддонов, Steam/IP, серверные профили и механизм подписанного обновления не менялись.

Локальная генерация и интерфейс проверены автоматически. Игровую приёмку полного комплекта 0.6.1 ещё предстоит провести.
