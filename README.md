# ZoneLink 0.6.1.3 для Windows x64

ZoneLink — клиентский лаунчер существующей установки xrMPE. Архив не содержит игру, игровые аддоны, изменённые OGF/DDS/DB или чужие сохранения.

## Установка и запуск

1. Распакуйте `xrMPE-Launcher-win-x64.zip` в отдельную папку с правом записи. Запустите `Xrmpe.Launcher.exe`. Windows x64 и установленный xrMPE обязательны; .NET включён в пакет.
2. Укажите папку установленного xrMPE, в которой находятся `addons`, `bin`, `patches` и `fsgame.ltx`.
3. Для PvP выберите `xrmpe_pvp.addon`. В «Мастерской» включите «Светящиеся 3D-повязки ZoneLink». При первом включении лаунчер автоматически соберёт локальный косметический DB из ресурсов **вашей** установленной игры. Дополнительных загрузок и ручного копирования нет.
4. Запустите PvP обычным способом или через Steam. Косметика применяется только к PvP-клиенту; выделенный сервер и другие аддоны запускаются без неё.

Первое включение занимает некоторое время и требует свободного места для временных файлов. Сборка допускается только для проверенных архивов xrMPE и PvP 1.4.7. Если SHA-256 локально собранного косметического пакета отличается от эталона, ZoneLink предлагает запустить игру без повязок, включить их на свой риск или отменить запуск. Проверки игрового аддона, структуры DB и цифровой подписи обновлений обязательны. Галерея локально создаёт текстурированные статические ракурсы из установленной игры; это не игровые скриншоты и не доказательство качества посадки на каждой модели.

## Отключение и откат

Переведите переключатель в «ВЫКЛ» и запустите игру снова: ZoneLink не передаст дополнительный `-fsltx`, поэтому вернётся исходный вид костюмов. Оригинальные архивы не перезаписываются. Локально собранный пакет остаётся в профиле пользователя для следующего включения. Для возврата к прежнему лаунчеру закройте ZoneLink и запустите сохранённую версию из её отдельной папки; установленная игра и её настройки при этом не меняются.

## Совместимость и ограничения

- Сохранены выбор установленных аддонов, 39 проверенных владельцем PvP-карт, профили сервера, Steam/IP, список серверов и подписанные обновления.
- Аддоны лично проверены владельцем в игре до этой сборки. **Сама 0.6.1.3 не прошла новую сетевую игровую приёмку**; клиент и сервер не запускались при подготовке этого пакета.
- Настоящий emissive-материал ранее проверен в игре на одной стартовой форме (обе руки, бег, прыжки). Для всех 30 покупаемых костюмов и двух оставшихся стартовых форм есть статическая проверка структуры, но визуальная посадка и LOD в игре пока не подтверждены. Bloom зависит от графического режима.
- Для игры с друзьями у всех должны совпадать версии xrMPE и активного аддона. Работа приглашений Steam на разных ПК требует отдельной проверки с другом.

## Права и состав

Проектные скрипты собирают косметический архив на компьютере владельца игры. В публичном ZIP нет оригинальных либо изменённых игровых моделей и текстур. Права на S.T.A.L.K.E.R. и xrMPE остаются у их правообладателей; локальный DB не предназначен для отдельного распространения. Предпросмотры создаются локально из игровых ресурсов и не входят в публичный архив. Встроенные CPython, NumPy, Pillow, .NET и Avalonia сопровождаются текстами лицензий в `app/LICENSE.txt` и `app/THIRD-PARTY-NOTICES.txt`.

Папка `app` включает лаунчер и его зависимости. Игровые исполняемые файлы и секреты издателя в неё не входят.
