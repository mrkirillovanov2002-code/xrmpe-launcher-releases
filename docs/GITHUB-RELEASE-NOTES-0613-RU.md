# ZoneLink v0.6.1.3 — восстановление локальных 3D-повязок

Исправлено восстановление повреждённой копии `armbands.db`, которую ZoneLink создаёт для запуска PvP. При отличии SHA-256 локально собранного косметического пакета от эталона лаунчер показывает предупреждение: запустить без повязок, включить их на свой риск или отменить действие. Выбор принудительного включения относится только к проверенному пакету и сбрасывается при смене его содержимого или сборщика.

Проверки цифровой подписи обновлений, игрового аддона и структуры косметического DB сохранены. Оригинальные игровые архивы не заменяются; повязки остаются необязательными и не подключаются к dedicated.

Игровая проверка этой сборки и поведение на ПК пользователя, сообщившего об ошибке SHA-256, пока не подтверждены. Готовые игровые OGF/DDS/DB не входят в публичный архив.
