# ZoneLink v0.6.1 — светящиеся 3D-повязки без ручной установки

В «Мастерской» появился один переключатель светящихся 3D-повязок для PvP. При включении ZoneLink автоматически собирает локальный косметический пакет из ресурсов установленного xrMPE; при выключении следующий запуск игры использует исходный внешний вид. Публичный архив не содержит игровые OGF/DDS/DB.

Сохранены установленные аддоны, PvP-карты, Steam/IP, создание сервера, список серверов и подписанные обновления. Бинарный пакет включает Windows x64 self-contained приложение, локальный сборщик и код локальной генерации текстурированных предпросмотров 30 костюмов.

Проверены сборка, автоматическая генерация точного локального пакета, интерфейс и ВКЛ/ВЫКЛ без игрового запуска. В игре ранее подтверждена одна стартовая форма; посадка на остальных костюмах и совместная игра друзей на разных ПК в этой сборке ещё требуют ручной приёмки. Подробности и откат — в `README-RU.md`.
